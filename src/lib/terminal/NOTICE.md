# Terminal migration attribution

The settings, registration and command/view presentation retain code from
`lapismd/lapis-plugin-terminal`, licensed AGPL-3.0-or-later. Its source and
history remain available in that sibling repository. The accompanying
`LICENSE.txt` preserves its licence. The new rendered-frame client, viewport and
native runtime are public `lapismd/lapis-terminal` exports under Apache-2.0.

The former Ghostty/raw-output bridge and web connection configuration are
replaced; no old native host runtime is included.
