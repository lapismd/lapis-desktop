Memory uses normal vault Markdown, metadata and search. Daily/curated notes
share stable entry anchors. Durable receipts retain provenance,
activation/checkpoints, prepared writes, deletion and forgetting state
independently of search indexes. Folder moves stop on collisions, roll back
failed settings saves and retain a recovery receipt on interruption. User edits
remain visible; generated mutations use the existing App-owned conflict
workflow.
