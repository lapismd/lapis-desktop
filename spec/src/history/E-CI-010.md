The E-CI-007 transport fault itself passed its leaf tests, but the actual
session factory supplied the observed call only to Tasks. Its native editing
port used the default invoke directly, so the guarded saved-text read never
crossed the acceptance fault boundary. No handoff error was injected.

The new regression constructs the real session and ports. It stubs unrelated
vault/database startup only, then observes the shared transport's exact calls,
selected session/path and one-shot refusal. The default invoke fails if a port
bypasses injection. This repairs the private composition boundary rather than
adding ambient transport mutation or weakening the native Properties assertions.
