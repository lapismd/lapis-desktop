The observed PR56 Linux x86 job spent21minutes10seconds installing WebKit/GTK
dependencies, then reached the60-minute job timeout during a cold release build.
Its Rust cache reported no hit. The same workflow already used the published
multiarchitecture Desktop CI image for Quality and Unit; that image contains
Rust1.99 and the complete Tauri GTK/WebKit build surface but the Linux matrix
repeated runner cleanup, apt installation and Node/Rust provisioning.

The Linux matrix now uses the existing immutable image digest on both native
runner architectures. It removes runner cleanup, apt/WebKit installation and
redundant Node/pnpm/Rust setup, retains workflow-token registry authentication,
and raises the cold safety timeout to90minutes. Rust caches restore on selected
runs, write only on canonical main and never save failed/cancelled outputs.

Schema2 now distinguishes selected Rust tests from release-binary compilation.
An exact Rust integration-test change runs portable x86 Rust evidence without
building either release binary. Renderer, dependency-graph and production Rust
changes retain both Linux builds. Dependency-automation changes run governance
tooling without Rust; root Cargo, CI planner, shared infrastructure and unknown
ownership still fail closed to complete Linux coverage.

Before editing, the focused planner/image cohort passed18/18. After editing, the
planner cohort passes19/19, including the new dependency-automation,
dependency-graph and Rust-test/build cases. Hosted image pulls, cold/warm build
timing and cache-size reduction remain required before claiming the ten-minute
feedback objective or adopting sccache/compiled dependency images. This change
does not qualify macOS UI, release publication or visual baselines.

The first PR57 audit attempt failed closed because the live registry report no
longer contained the approved Picomatch finding. The stale exception was removed
without changing advisory matching, severity, production blocking or either
remaining exact development-only exception. The same live full and production
audit reports then passed locally with zero production findings.

The replacement run then exposed the retained literal-runner policy assertion:
the Linux job now resolves `runs-on` through `matrix.os`, so the assertion could
not see its Ubuntu values. The policy now verifies that expression and every
matrix entry, retaining Linux-only execution while admitting both native Ubuntu
architectures.
