E-CI-003 and E-CI-004 contain valid references to files removed before their
receipts were appended. The old lookup inspected only each receipt's immediate
snapshot and parents. An explicit original PR base masked that limitation; a
later default-range command exposed it. The repair first reuses the existing
snapshot set and consults only enclosing ancestry for a still-missing path.
Fresh receipts retain their current/base requirement and cannot use this
historical fallback.

The internal validator accepts an explicit fixture base so isolated histories
remain independent of the parent CI job's actual repository range. Normal
callers retain the existing environment/default range selection.
